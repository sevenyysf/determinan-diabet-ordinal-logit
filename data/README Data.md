# Data

Analisis ini menggunakan dataset **CDC Diabetes Health Indicators** (BRFSS 2015)
dari UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/891/cdc+diabetes+health+indicators

File yang dipakai oleh script:

```
diabetes_012_health_indicators_BRFSS2015.csv
```

- 253.680 baris, 22 kolom
- Variabel respons: `Diabetes_012` (0 = tidak diabetes, 1 = prediabetes, 2 = diabetes)
- Tidak ada missing value

Simpan file ini di folder `data/` agar script `R/Analisis_Determinan_Diabetes.R` dapat membacanya.
